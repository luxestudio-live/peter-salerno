# Peter Salerno — The Man With The Magic Message

The official website for **Peter Salerno** — Speaker, Author, Podcast Host (*Happy Business Radio*), Business Mentor, Presenter, and Entertainer.

Peter unites decades of front-line business leadership and advisory experience with stagecraft, humor, and practical wisdom to inspire lasting personal and organizational transformation.

## Features

- **Interactive 3D Book Experience:** Flip, read, and explore Peter's books with realistic 3D paper rendering and chapter navigation.
- **Audio & Podcast Hub:** Integrated *Happy Business Radio* player with playback controls and episode showcase.
- **Keynote & Workshop Showcases:** Topic overviews, audience takeaways, and speaking credentials.
- **Booking & Enquiries:** Clean direct contact and event consultation flows.
- **Responsive & Accessible Design:** Crafted with modern typography, smooth motion, and responsive layouts.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **UI & Components:** [React 19](https://react.dev/), [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/luxestudio-live/peter-salerno.git

# Navigate into the project directory
cd peter-salerno

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

### Production Build

```bash
npm run build
npm run start
```
